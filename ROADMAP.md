# AEGIS engineering and research roadmap

This roadmap records intended work, not product, performance or patent claims.
Every milestone must be supported by tests and reproducible evidence before its
status changes to complete.

## Completed checkpoint — v1.2 Enterprise Control Boundary

- signed offline entitlements and fail-closed license validation;
- host-assigned viewer, analyst and administrator scopes;
- append-only, HMAC-linked command receipts;
- sixteen-workspace native desktop console;
- resident Windows node packaging path; and
- 88 passing automated tests plus source and wheel validation.

## Next — v1.3 Multi-Model Temporal Intelligence

1. Define a versioned sequence-dataset contract with grouped, temporal and
   out-of-distribution splits.
2. Add reproducible classical baselines and compact GRU, TCN and Transformer
   shadow candidates through an optional deep-learning dependency group.
3. Add repeated-seed evaluation, calibration, confidence intervals, ablations,
   drift slices and compute/latency measurements.
4. Add a model registry entry for every run, including data fingerprint,
   configuration, code revision, environment and artifact hashes.
5. Add guarded ensemble inference. Neural predictions remain advisory and
   cannot directly authorize containment or deception deployment.
6. Add a seventeenth **Neural Research** workspace for comparison, failure
   analysis, provenance and promotion decisions.
7. Expand the learning guide, paper method, experiment protocol and IP register
   only with statements supported by executed evidence.

## Planned later milestones

- **v1.4 — Enterprise Sensor Federation:** authenticated, privacy-bounded
  adapters and deployment observability for authorized environments.
- **v1.5 — Continual and Federated Learning:** replay, drift response,
  poisoning resistance, privacy accounting and rollback experiments.
- **v1.6 — Evidence Anchoring:** exportable audit checkpoints, external signing
  interfaces and independent verification packages.
- **v2.x — Hardware Trust Research:** TPM/HSM-backed keys and a separately
  reviewed enforcement appliance or accelerator prototype.

Public source publication, a public paper preprint and public demonstrations are
separate disclosure decisions and remain blocked until IP review.
