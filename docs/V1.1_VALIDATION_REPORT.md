## Windows acceptance procedure

On the Victus Windows laptop:

1. extract the v1.1 source archive;
2. double-click `BUILD_AEGIS_EXE.bat`;
3. retain the complete terminal log;
4. verify the generated ZIP against its `.sha256` file;
5. install on a disposable or isolated Windows account first;
6. capture the AEGIS splash, Mission Canvas, System & Agents, and Windows
   Services screens;
7. close `AEGIS.exe` and confirm `AEGISNode` remains `Running`;
8. reboot and confirm delayed automatic start plus desktop attachment;
9. test upgrade and data-preserving uninstall;
10. record CPU, private memory, database growth and collector permissions.

Only after those checks pass should the artifact be called a Windows-validated
desktop build. A signed/licensable release still requires independent security
review, Authenticode, SBOM, least-privilege service configuration and an
enterprise pilot using authorized data.
