# AEGIS collaboration code

AEGIS research must remain lawful, defensive, evidence-led and respectful.

Contributors and reviewers are expected to:

- work only with systems and data they are explicitly authorized to use;
- separate activity correlation from claims about a person's identity;
- report uncertainty, negative results and known limitations honestly;
- protect confidential research, personal data, credentials and signing keys;
- challenge ideas without attacking people; and
- stop work that could enable malware deployment, hack-back, indiscriminate
  surveillance or unauthorized access.

Unsafe, deceptive, discriminatory, harassing or unlawful conduct is not
accepted. The repository owner may remove access or reject work that violates
these boundaries.
